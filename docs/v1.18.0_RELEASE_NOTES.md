# xAI SDK Go v1.18.0 Release Notes

This release aligns the Go SDK with the official xAI Python SDK v1.18.0 while
preserving the patched Go, gRPC, protobuf, and genproto dependency baseline.

## Python SDK parity

- Added `xhigh` reasoning effort and its generated enum value.
- Added the `grok-4.6` model literal.
- Completed the exact Python model catalog, including previously omitted Grok 4.5,
  Grok Build, and Grok Imagine literals.
- Added the upstream `none` reasoning effort value to the typed and generated surfaces.

## Generation

`buf.yaml` now declares the Google APIs dependency used by the xAI protos, and
`buf.lock` records it for reproducible generation.

## Installation

```bash
go get github.com/ZaguanLabs/xai-sdk-go@v1.18.0
```
