# xAI SDK Go v1.17.1 Release Notes

**Release Date:** August 8, 2026

## Python SDK v1.17.1 Parity

This release aligns the Go SDK version with the official Python SDK v1.17.1 tag.
The upstream source comparison against v1.17.0 found no public API, protobuf,
or behavior changes; only the Python package version metadata changed.

## Validation

- Official Python source tag downloaded, built, and its source distribution unpacked.
- Full Go tests, build, and vet completed for the release.
