# xAI SDK Go v1.19.0 Release Notes

This release aligns the Go SDK with the official xAI Python SDK v1.19.0.

- Image quality and current image model catalog support.
- 1080p and reference-audio video generation support.
- Server-side image generation/editing tools and decoded image outputs.
- Upstream-compatible gRPC User-Agent and correct tool-result replay IDs.
