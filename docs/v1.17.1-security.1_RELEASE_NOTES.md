# xAI SDK Go v1.17.1-security.1 Release Notes

This security release preserves parity with the official xAI Python SDK v1.17.1 while updating vulnerable Go runtime and transport dependencies.

## Security updates

- Go toolchain updated from 1.25.11 to 1.25.12, addressing GO-2026-5856 in `crypto/tls`.
- `google.golang.org/grpc` updated from v1.76.0 to v1.82.1, addressing GO-2026-6061.
- Matching `genproto` and protobuf dependencies refreshed.

## Installation

This is an explicit security prerelease so that v1.17.2 remains available for the next upstream xAI SDK synchronization:

```bash
go get github.com/ZaguanLabs/xai-sdk-go@v1.17.1-security.1
```

## Validation

- `go test ./... -count=1`
- `go test -race ./...`
- `go build ./...`
- `go vet ./...`
- `govulncheck ./...` reports no vulnerabilities in called code
