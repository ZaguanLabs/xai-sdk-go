# xAI Go SDK v1.20.0

Matches the video-generation additions in official Python SDK 1.20.0:

- Pin the final frame with `GenerateOptions.LastFrameURL` or `LastFrameFileID`.
- Pin intermediate frames with `GenerateOptions.Keyframes`, using URL or file-ID images and timestamps in seconds.
- Generation, deferred start, and batch preparation share the new protobuf fields.
- `Start` and `Generate` validate conflicting sources and blank keyframe images. `PrepareChecked` adds validation for batches while existing request-builder signatures remain compatible.
- Keyframe timing, count, and model constraints are enforced by the service, matching Python.

The PyPI source archive was SHA-256 verified, built with `python -m build`, and the resulting sdist unpacked. Full Go tests, build, vet, protobuf wire-roundtrip tests, and whitespace checks pass. No live API calls were made.
